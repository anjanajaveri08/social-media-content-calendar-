# Social Media Content Calendar

A responsive, beginner-friendly web app for organizing social media content ideas. Built with HTML, CSS, and vanilla JavaScript as a digital marketing portfolio project.

## Features

- Add a post title, platform, publishing date, content type, caption, and hashtags.
- View posts sorted by publishing date.
- Filter posts by social media platform and status.
- Mark posts as scheduled or published.
- Delete posts that are no longer needed.
- View summary counts for all, scheduled, and published posts.
- Save posts in the browser with `localStorage`.
- Responsive layout for desktop and mobile screens.

## Built with

- HTML5
- CSS3
- JavaScript (ES6)
- Browser Local Storage

## Getting started

No installation or build tools are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add your first post using the form.
4. Use the filters and status buttons to manage your calendar.

## How it works

- **HTML** provides the form, summary cards, filters, and post list.
- **CSS** styles the interface and makes it responsive.
- **JavaScript** handles form submission, filtering, status changes, deletion, and rendering.
- **Local Storage** saves posts in the current browser on the current device.

## Limitations

This is a front-end demo. It does not publish content to social media platforms or sync data across devices. Posts are saved only in the browser where they were created. Real social media scheduling would require platform APIs, authentication, and a backend service.
